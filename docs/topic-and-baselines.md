# 预算约束下基于RSI的VLA–Harness持续学习：课题与基线

用户于2026-10-27确认本课题。本文是有针对性的叙述性文献/源码审计，不是穷尽性系统综述。原始来源为arXiv、作者项目页和固定版本官方仓库。优先复现论文，再做自有方法。

## 冻结的研究范围

第一阶段冻结VLA与Qwen3-VL-8B-Instruct权重，更新任务harness，并研究进化Agent能否持久改进“经验选择与复验证分配”策略。预算、工具权限、评分器、划分、最终测试反馈均不可修改。第二阶段才考虑VLA参数更新。不以局部错误恢复为主线。

严格RSI证据：将新旧改进策略放在相同初始任务harness、相同初始经验、相同模型与预算上，在未参与策略选择的新任务序列中比较后续学习效果。多轮改程序本身不构成改进器变好的证据。

创新边界：主动实验选择、按未来收益筛选记忆、经验复用、回归门禁均已有直接近邻。候选差异收窄为：在固定总预算内，持久演化经验选择/历史能力复验证策略，并检验其在新任务序列上是否提高学习效率且保留旧能力。不是已证实首创；必须与EmbodiedRSI、AdaHVLA、HCL核对。

## 实验设计

主基准仍优先RoboTwin2.0。先校准Harness VLA官方RoboTwin C2R入口与本地版本的机器人、资产、动作、观测、初始化筛选和步数，不把相同任务名当相同分布。两个已有开发任务stack_blocks_two/handover_block先用于原生自主执行资格验证，再选正式任务面板。历史场景仅作开发，不能进入独立最终测试。

原始系统复现与共同后端适配分开报告。当前RPent RoboTwin默认LingBot-VLA，不是pi0。先审计其公开权重、数据来源、归一化及语言接口；选择可运行公共底座后固定所有harness比较的checkpoint、可用示范与工具。pi0是条件可选底座，不为贴标签而更换；已有DexMimicGen pi0训练和结果完全独立。

最低对照：冻结系统；固定改进策略但允许任务harness更新；允许改进策略持久更新的RSI。本方法与随机/均匀分配、固定信息价值选择做等预算对照。AdaHVLA/RoboRSI原生机制保留，不删关键角色再冒充完整系统。EmbodiedRSI若缺代码，必须标明哪些模块重实现以及缺失项。

所有角色的提案、分析、验证、拒绝、自我修改成本都入账。token/调用、环境动作步/初始化步、训练与墙钟分别报告；预算采用预注册多维上限，不能把不同模型tokens直接当等价算力。最终测试成本独立列出，反馈不可回流。

主要指标：随累计交互预算变化的新任务和全任务成功率、旧任务能力保持、未见组合/任务序列迁移、经验规模、实际调用成本、预算内饱和。每方法首轮目标2任务各5配对开发场景，之后6任务与至少3独立学习序列；正式规模/顺序/分配在执行前冻结，5场景不支撑优越性结论。
