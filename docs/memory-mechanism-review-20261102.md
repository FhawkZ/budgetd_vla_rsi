# 持久经验的证据、复验证与失效：有限机制核查

2026-11-02。结论：**当前“证据门控记忆＋不确定性预算”方案 no-go，不作为 RA-L 核心，不启动新仿真。** 这只关闭当前方案，不等于否定 VLA–Harness/RSI 整个研究方向。已有方法覆盖其主要机制；我们尚未建立一个有独立收益证据、可观测且区别于这些机制的机器人问题。

本报告按预先限定的四篇论文查阅原文方法与相关附录，并核对已固定的官方代码。它是单人、定向机制核查，不是系统综述或全领域新颖性证明。不将论文自报结果当本地复现成绩。四篇当前均按预印本处理，本次未核实录用。

## 论文与固定实现不能混同

RoboRSI 固定提交 `90c8569705bf4004a4f79e34e650c87ab7f075d4` 的 Reviewer 指令明确要求独立检查最终图像，禁止把未验证成功写成经验。Manager 和 `episode_gate.py` 进一步区分源任务安装与跨任务晋升：源任务要求完整配对结果、候选至少成功一次且不劣于原技能，跨任务路径再检查其他调用者。[固定代码](https://github.com/nssmd/RoboRSI/blob/90c8569705bf4004a4f79e34e650c87ab7f075d4/roborsi/agents/evolution/episode_gate.py)

因此，不能把论文“至少两种子成功”的描述无条件套到所有实际发布路径。该文件的 `cross_task_gate` 也未像 `source_task_gate` 那样显式核验每个种子结果完整性，并且候选写入路径指向 LIBERO；这是阅读所得的实现限制，本轮未执行门禁，未证明实际误晋升，更不能把修补它作为论文创新。函数中按已记录调用选调用者，也不等于静态完整依赖覆盖。后续若适配必须明确版本和范围，不能削弱对照。

HCL 的固定 **V1 分支**提交 `a6e5a01536ac8d42ca28f0a82efa223869c8c48d` 与 arXiv **v2** 是不同版本标识。此前已核的主实验 profile 使用 `plasticity + historical_loss_budget`；不能将 balanced 分支的 cheap screening 混入主配置并宣称复现。现有 `hcl_robotwin_adapter` 仍只是门禁/筛选映射。[固定实现](https://github.com/RL-MIND/Harness-Continual-Learning/blob/a6e5a01536ac8d42ca28f0a82efa223869c8c48d/hcl/pipeline.py)

EmbodiedRSI 本轮读取到 HTML 方法正文；其中引用的附录 C–I 未在本次 HTML 提取中出现，PDF 读取长时间未返回后终止。故不推断未读附录的精确阈值、缺失结果处理或校准细节；没有运行其官方实现。论文机制足以排除上述宽泛创新主张，但不足以宣称完整复现或所有边界都已审计。

## 什么才算尚待证明的问题

| 待审想法 | 已有机制之外必须增加的实质内容 | 可证伪条件及当前证据 | 决策 |
|---|---|---|---|
| 可信物理结果驱动的持久经验更新 | 必须指出一种可测物理后条件误判怎样持续污染后续执行，并给出区别于新观察检查、配对复验证和一般置信门控的学习机制。 | 若统一观察后强固定检查/既有门禁已消除损失，或方法只因额外传感/调用获益，该机制主张不成立。目前没有这种开发证据与有效候选。 | no-go；“命令≠抓持”只是必要接口事实。 |
| 考虑无效场景/缺失结果的记忆提交 | 必须证明缺失机制具有明确机器人结构，且处理它在同观察、同全成本下提升真实任务能力及保留；单纯 `unknown` 拒绝属于实验规范。 | 若强固定 fail-closed 与完整分母报告已经足够，或只有删掉无效样本后看似提升，则无方法收益。目前仅有基础设施/场景有效性记录，不是新学习机制证据。 | 不开新实验、不从验证失败生成新候选。 |
| 自进化的探索/历史复测预算器 | 需先有真实有益共享更新与自然的收益/保留权衡，再证明学习后的预算器在重置执行器、经验和新序列上优于强固定信息价值规则。 | 若无有益更新、复测成本不可节约，或收益来自更多试验/更强模型/弱对照，主张不成立。目前第一项前提尚未满足。 | 600 episode 与分配器比较继续不启动。 |

不能把这些“重新立项的必要条件”当成已提出或已实现的创新。当前没有满足条件的新在线协议。

## 与本地实验的关系

固定 50-waypoint 控制器是可用的 incumbent；其开发面板堆叠 2/5、交接 1/5，不是稳定总体成功率。已关闭夹爪候选的独立验证有 9 个完整配对：堆叠双方 2/5，交接双方 1/4，未观察到收益；另一个交接配对在动作前无效。继续保持“不晋升、停止该候选空间”，不把部分平局说成统计等效。本轮只引用已经关闭的汇总，**未读取验证轨迹分类、未将验证反馈提供给模型或生成后继候选**。

当前接受的共同更新为 0，更新后遗忘为未测，严格 RSI 成果为 0。HCL 官方测试通过及部分门禁适配不等于完整论文结果复现；RPent/RoboRSI 本地模型适配的负结果也不等于原论文被否定。本轮新增模型调用、VLA 推理、仿真与物理步全部为 0。
