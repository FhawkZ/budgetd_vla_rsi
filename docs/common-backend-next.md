# 共同 VLA 后端下一步（2026-10-30）

状态：设计草案，不能据此直接启动大批量实验。已执行的独立两场景 VLA-only 协议见 configs/vla-publiclang-dev2-20261030-frozen.json；不得重开预算。

## 已排除与仍存在的混淆

公共语言已实际到达 RoboRSI 的 Planner、Engineer、Reviewer；这是传输资格，不是任务成功。GraspGen 关闭时移除依赖它的三个工具，但模型仍可能幻觉调用这些名字。一次独立原生交接在第10次生成触发未声明工具而中断，Reviewer未到达。不得通过工具重命名、补动作或额外重试把它算成功。

原生 RoboRSI 使用代码/解析技能，放在单独复现表；统一 VLA 比较使用固定 RPent–LingBot、原生观测、动作接口、公共语言和评分器。原生系统的单次负结果不能证明我们的分配器更优。

## 有限推进顺序

1. 关闭两场景 VLA-only 开发协议，保存每次推理图像/机器人状态/动作/语言及初态指纹。这两场景仅开发，允许后续对照复用相同初态，但不能冒充独立最终测试。
2. 审计 RPent 公共语言注入、总调用门限和 sample_world_xyz 工具契约。历史 flat pixel array 错误是模型输出不合约；不自动改写模型参数，也不重跑旧16K/32K协议。
3. 新的固定 harness 与论文适配 harness 共用上述低层后端、1200动作上限、相同初态和语言。先独立冻结小规模开发预算，报告总成本向量（Qwen输入/输出、VLA调用、GPU分配秒、仿真步、失败次数）。不能因某方法多了高层计算而仍称等总成本。
4. 只有自主执行和旧任务非零能力成立，才冻结新的两任务学习协议。共享路由/经验更新必须确实可能影响旧任务；记录更新前后完整Agent成功率、回归和成本。若底层一直失败，先作一次有界控制/语言分布诊断，不堆RSI轮数。
5. 主研究比较固定均匀、强固定 VOI+依赖风险、可进化分配器；三者候选生成器、特征、提交门禁、权重相同。自改/筛选/失败费用计入同一预算。仅迁移分配器到重置执行器和经验的新序列，才检验严格RSI。

## 失败后的决策

- 未声明工具：保留原生失败；若要采用约束解码，必须独立资格并对所有相关方法同样启用，标明模型适配，不能当论文原模型复现。
- Reviewer预算语义错误：继续依靠外部硬预算；不要让其改评分器或放宽提交条件。语义能力没有被读图资格证明。
- VLA偶发成功但方差大：先扩充预声明开发场景，估计方差和每episode成本，再定样本量；禁止挑成功seed。
- 固定VOI与进化无差异：检查自改成本和规则迁移；无证据时降低RSI主张，保留预算化复验证问题，不无限加模块。

目前没有新方法对照胜出、接受的共同后端持久更新或遗忘测量。600episode计划仍为草案。
